# Mithana Automation — Cinematic Portfolio

A personalized React + TypeScript + Vite portfolio based on the supplied cinematic reference design, rebuilt with Srinivasa Reddy Mithana's professional details.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. For a production build, run `npm run build`.

## Included
- Responsive cinematic black / warm-gold visual system.
- Motion-based hero, scroll reveals, reading-progress indicator, interactive navigation and animated technical illustration.
- Career timeline and skills based on the supplied résumé.
- One featured Fleet & Workforce Management case study based on the supplied FFICO work-progress sheet.
- The dashboard visual is explicitly labeled an illustrative UI concept, not a live client screenshot.
- Resume PDF at `public/resume.pdf`.
- Email, phone and WhatsApp contact links.
- Reduced-motion and mobile layout support.
